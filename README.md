

# Toolsy

Toolsy is an e-commerce website for browsing and purchasing hardware and electrical products. The platform is designed for anyone in need of quality tools and fittings for home improvement, repairs, or professional projects.

## Features

- Explore a catalog of hardware and electrical items such as door handles, curtain rods, faucet mixer taps, and more
- Add products to cart and manage selections before purchase
- Clean and intuitive interface focused on ease of use and efficient browsing
- Optimized product display for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Browse products, add items to your cart, and follow on-page instructions to complete mock purchases.

## Project Structure

- `index.html` — Main homepage
- `products.html` — Product catalog
- `buy.html` — Purchase and checkout page
- `payment.html` — Payment workflow
- `script.js` — Core logic for UI and cart actions
